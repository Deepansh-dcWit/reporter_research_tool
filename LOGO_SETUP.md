# Logo Setup Instructions

To complete the UI setup, please save the DC Witness logo:

1. Save your DC Witness logo screenshot as: `dc_witness_logo.png`
2. Place it in the same folder as `main.py`
3. The logo should be a PNG file with transparent background (if possible)

The app will automatically:
- Display "Research Tool" in the top-left corner
- Show the DC Witness logo as a faded watermark in the center (15% opacity)
- Keep the logo in the background while chat messages appear on top

If you don't have a clean logo file, you can:
- Extract it from your screenshot
- Or I can help you create a simple text-based version

Once the logo file is in place, restart the Streamlit app!
